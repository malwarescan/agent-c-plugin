# Agent C plugin for Claude Code

[Agent C](https://agentc.croutons.ai) finds what keeps a small business out of ChatGPT, Claude and Gemini answers, and writes the fix. This plugin lets Claude Code make those fixes in your website's code. Nothing goes live: every change waits for you to review.

```bash
claude plugin marketplace add malwarescan/agent-c-plugin
```

```bash
claude plugin install agent-c@agent-c
```

Then run `/mcp` in Claude Code, pick **agent-c** and sign in with your Agent C email.

See [plugins/agent-c](plugins/agent-c/README.md) for what it does.

You need an [Agent C](https://agentc.croutons.ai) account with a checked website.
